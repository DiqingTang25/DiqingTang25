## 代表项目

### LabNote Agent — AI 实验数据治理平台

直击科研"复现危机":多模态大模型把散乱的实验文件解析成结构化实验卡片,逐字段标注置信度与来源,再自动生成分步复现协议与审计报告,让每一次实验都成为可核可溯的科研资产。

- 线上系统:https://labnote.tech
- 源码:https://github.com/DiqingTang25/labnote-agent
- 技术:React 19 SSR · PostgreSQL + pgvector · RAG 混合检索 · FastAPI 设备网关 · MCP

### AI Agent 全自动化测评系统

面向 AI 教学助手的自动化测评平台:10 维度三层级联评分(L1 规则 + L2 语义 + L3 跨模型 LLM Judge 投票)、SHA-256 证据链封存、自进化改进闭环,云端 CI 每 30 分钟自动巡检。

- 源码:https://github.com/DiqingTang25/eval
